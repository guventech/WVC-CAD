# Roadmap (near-term)

Public priorities only. This is **not** a promise of dates or a full business plan.

## Now / next

1. **Sample sketches** — checked-in `.sketch.json` examples for first-run learning.
2. **Quick-start polish** — short tutorial path and clearer onboarding copy.
3. **Reliability** — fix issues reported by early users; expand Playwright smoke where it protects save/reload and dimension edit.
4. **Alpha feedback** — invite a small group; triage GitHub Issues before large features.
5. **Installer polish** — custom icons and a signed Windows build when the Rust toolchain and branding are ready.

## Explicitly not current work

- Payments, accounts, cloud sync, analytics, or AI features
- 3D solids / extrusion (Pad/Pocket) until the 2D core stays solid under real use
- Renaming away from WVC-CAD (codename stays unless a cleared product name is chosen later)

Solver residual/column scaling remains **deferred** with honesty docs (ADR-052).
