# Branding

## App mark

- `icon-source.png` — 1024×1024 master (concept **A — refined axes**, shipped for alpha).
- Concept mockups (for comparison):
  - `icon-concept-a-axes.jpg` — dark plate + cyan X/Y + origin (chosen)
  - `icon-concept-b-monogram.jpg` — W monogram on engineering blue
  - `icon-concept-c-rectangle.jpg` — constrained rectangle silhouette

Web favicon is hand-tuned SVG: `public/favicon.svg` (not generated by Tauri).

## Regenerate platform icons

```bash
npx tauri icon branding/icon-source.png
```

This overwrites `src-tauri/icons/**` including Windows `icon.ico`. Rebuild the installer with `npm run tauri:build` when publishing a new release.
