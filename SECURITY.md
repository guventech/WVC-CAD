# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Prefer contacting the repository owner via GitHub (private vulnerability reporting if enabled, or a private message to the account that owns this repo). Include:

- A short description of the issue
- Steps to reproduce (if applicable)
- Impact assessment if known

## Scope notes

- This project is a local 2D sketcher (browser / optional Tauri desktop shell).
- There is no cloud backend or API keys in the application today.
- Do not commit secrets, tokens, or private keys into the repository.
