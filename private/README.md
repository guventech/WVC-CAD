# Private local notes (gitignored)

This folder is for **machine-local** strategy and brand work that must not appear in the public repository.

- Everything under `private/` is ignored by git **except** this README.
- Put copies or working notes of confidential plans here if you want them next to the repo (for example a local `plan.md`). Prefer keeping the canonical file outside the tree when possible.
- Never force-add ignored files. Never paste confidential strategy into `README.md`, Issues, PRs, or release notes.

| File | Purpose |
|------|---------|
| `brand-shortlist.md` | 3 name candidates + clearance-check notes |
| `alpha-testers.md` | Private list of invitees / feedback notes |
